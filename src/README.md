# Исходный код NEVOBRAIT

В этой папке будут храниться исходные файлы проекта (React-компоненты, стили, скрипты) до момента сборки.

## Текущий статус
- Основной сайт собран в единый файл `index.html` (минифицирован для защиты от копирования).
- Все скрипты защиты и терминала встроены в `index.html`.
